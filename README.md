# java-racingcar-precourse

## 💻 기능 구현 목록

### 1️⃣ 프로그램 시작 문구 출력

```text
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
```

- 프로그램을 시작하면 위와 같이 `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`라는 문자열을 출력한다.

### 2️⃣ 사용자 입력 받기 1: 경주할 자동차 이름

```text
pobi,woni,jun
```

- 쉼표(,)를 기준으로 구분된 여러 자동차 이름을 입력받는다.
- 각 자동차 이름은 1자 이상 5자 이하의 영문자 또는 숫자로만 구성되어야 한다.
- 이름 조건을 만족하지 않을 경우 `IllegalArgumentException`을 발생시키고 애플리케이션을 종료한다.

#### ✅ 사용자 입력 검증 1 (자동차 이름)

- [검증] 입력값이 공백 혹은 비어있는 문자열인 경우 예외
- [검증] 쉼표로 구분된 각 자동차 이름의 길이가 1~5자가 아닌 경우 예외
- [검증] 자동차 이름에 공백이 포함되어 있는 경우 예외
- [검증] 자동차 이름에 중복이 있는 경우 예외
- 검증 실패 시 `IllegalArgumentException` 발생 및 애플리케이션 종료

#### 💾 자동차 정보(목록) 저장

- 입력값을 `,` 기준으로 분리하여 List<Car>에 저장

### 3️⃣ 사용자 입력 받기 2: 시도할 횟수

```text
시도할 회수는 몇 회인가요?
```

#### ✅ 사용자 입력 검증 2 (시도 횟수)

- [검증] 입력값이 공백 혹은 비어있는 문자열인 경우 예외
- [검증] 입력값이 숫자가 아닌 경우 예외
- [검증] 입력값이 1 미만(0 또는 음수)인 경우 예외
- 검증 실패 시 `IllegalArgumentException` 발생 및 애플리케이션 종료

### 4️⃣ 게임 플로우 상세

1. 게임 문구 출력
   ```text
   실행 결과
   ```
    - 본 경주 결과 출력 전에 위 문구를 한 번 출력한다.


2. 라운드 진행 (시도 횟수만큼 반복)
    - 각 라운드에서 자동차별로 0~9 사이 무작위 정수를 생성한다.
    - 생성된 값이 **4 이상이면 전진**, **그 미만이면 정지**한다.
    - 전진 시 해당 자동차의 진행 표시 문자열에 `-`를 1개 추가한다.
    - 라운드 종료 후 현재 상태를 다음 형식으로 출력한다.
      ```text
      pobi : --
      woni : -
      jun : ---
      ```
    - 라운드와 라운드 사이에는 빈 줄을 1줄 출력한다.


3. 최종 우승자 선별 및 출력
    - 가장 많이 전진한 자동차(들)를 우승자로 선정한다. (동점 가능)
    - 여러 명일 경우 입력받은 순서를 유지하여 이름을 쉼표(,)로 구분한다.
    - 출력 형식:
      ```text
      최종 우승자 : pobi,jun
      ```
    - **문구 뒤에 개행 없이 이어서 출력**한다.
